# OlcrtcWRT

OpenWrt LuCI application for managing olcrtc (TCP-over-WebRTC) and WDTT (WireGuard-over-TURN-Tunnel) clients.

## Structure

- `olcrtc-apk/` — OpenWrt package source
- `olrct-bin/` — prebuilt olcrtc binaries
- `free-turn-proxy-bin/` — prebuilt free-turn-proxy binaries
- `install-sing-box.sh` — interactive installer for sing-box / sing-box-extended

## sing-box installer

```bash
sh install-sing-box.sh
```
